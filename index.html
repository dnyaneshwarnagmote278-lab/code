Troubleshooting

  • “Failed to open serial port” = the port is busy. Close Arduino IDE (Serial Monitor/Plotter), other browser tabs using the Arduino (e.g. the old “Arduino Connection” page) and other serial apps.
  • Unplug and replug the USB cable, then connect again.
  • Pick the right port (not a Bluetooth COM port). Check Device Manager → Ports.
  • Baud rate must match Serial.begin(9600).
  • Use a data USB cable, not charge-only.
  • Open the page from a file, localhost or https.

Transmit Console

Arduino Sketch

const int LED_PINS[5]={2,3,4,5,6};
void setup(){
  Serial.begin(9600);
  for(int i=0;i<5;i++){pinMode(LED_PINS[i],OUTPUT);digitalWrite(LED_PINS[i],LOW);}
}
void loop(){
  if(Serial.available()>0){
    int m=Serial.read();
    for(int i=0;i<5;i++) digitalWrite(LED_PINS[i],(m>>i)&1);
  }
}

Components Used

  • Arduino UNO + USB cable
  • 5 × LEDs
  • 5 × 270Ω resistors
  • Breadboard + jumper wires
  • Laptop webcam

How It Works

  1. The webcam streams video to the browser.
  2. MediaPipe Hands finds 21 landmarks on your hand.
  3. Fingers are counted (0–5) and stabilised over several frames.
  4. The count is looked up in the Gesture Mapping.
  5. One byte (bit0 = LED1 … bit4 = LED5) goes over USB serial.
  6. The Arduino switches pins D2–D6.
